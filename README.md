# 💼 Ricardo Pinzón - Portfolio Profesional

Portafolio profesional desarrollado con **Next.js 16**, **Tailwind CSS v4** y **Framer Motion**. Este repositorio contiene mi currículum interactivo, proyectos y experiencias profesionales.

## 🚀 Tecnologías Utilizadas

- **Frontend:** [Next.js](https://nextjs.org/) (App Router)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)

## 🛠️ Instalación y Desarrollo

Para ejecutar este proyecto localmente, sigue estos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/Ruicki/CV.git
    cd CV
    ```

2.  **Instalar dependencias:**
    ```bash
    npm install
    ```

3.  **Iniciar el servidor de desarrollo:**
    ```bash
    npm run dev
    ```

4.  **Construir para producción:**
    ```bash
    npm run build
    ```

## 📂 Estructura del Proyecto

```text
src/
├── app/          # Rutas, layouts y páginas principales
├── components/   # Componentes UI reutilizables
├── data/         # Fuente de verdad (cv-data.ts)
├── features/     # Módulos específicos (Hero, Experience, etc.)
├── lib/          # Utilidades y configuración
└── types/        # Definiciones de TypeScript
```

## 📝 Documentación del Proceso (Spec-Driven)

Este proyecto sigue una metodología basada en especificaciones ubicadas en el directorio `.specs/`:
- `requirements.md`: Requerimientos y objetivos.
- `design.md`: Decisiones de arquitectura y diseño.
- `tasks.md`: Seguimiento de la refactorización.
